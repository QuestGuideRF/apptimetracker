# AppTimeTracker
**AppTimeTracker** — это приложение Windows Forms для отслеживания времени, проведённого в различных приложениях на вашем компьютере. Программа использует P/Invoke для вызова нативных Windows API для получения информации об активном окне и расчёта времени простоя.
## 🚀 Возможности
- Автоматическое отслеживание времени работы с приложениями
- Отображение статистики в реальном времени
- Простой и интуитивный интерфейс
- Минимальное потребление ресурсов системы
## 📋 Требования
- Windows (любая версия, поддерживающая .NET 8.0)
- .NET 8.0 SDK или выше
- Visual Studio 2022 (рекомендуется) или любая другая IDE с поддержкой .NET
## 🏗️ Структура проекта
Проект состоит из следующих ключевых файлов:
- **`AppTimeTracker.csproj`** — файл проекта, содержащий конфигурацию сборки
- **`AppTimeTracker.sln`** — файл решения, группирующий проект и его зависимости
- **`Program.cs`** — точка входа приложения. Инициализирует конфигурацию и запускает `MainForm`
- **`MainForm.cs`** — главная форма приложения. Содержит логику отслеживания использования приложений и отображения данных в ListView
- **`MainForm.Designer.cs`** — автоматически сгенерированный код для `MainForm`. Содержит метод `InitializeComponent`, который настраивает элементы управления формы
- **`ApplicationData.cs`** — класс, представляющий данные одного приложения (название и общее время использования)
- **`ApplicationListView.cs`** — класс, отвечающий за отображение данных приложений в ListView
- **`ApplicationTracker.cs`** — класс, отслеживающий время, проведённое в различных приложениях
## ⚙️ Как это работает
Приложение использует таймер для периодической проверки активного окна:
1. **Определение активного окна**: Используется функция Windows API `GetForegroundWindow()` для получения дескриптора активного окна
2. **Получение процесса**: Функция `GetWindowThreadProcessId()` получает идентификатор процесса окна
3. **Извлечение названия**: Класс `Process` используется для получения имени приложения из основного модуля процесса
4. **Расчёт времени простоя**: Функция `GetLastInputInfo()` определяет время последнего события ввода для расчёта времени простоя
Приложение обновляет статистику каждую секунду и отображает отсортированный список приложений с общим временем использования.
При закрытии приложения таймер останавливается, и время, проведённое в каждом приложении, логируется в отладочный вывод.
## 🔨 Сборка проекта
1. Убедитесь, что у вас установлен .NET 8.0 SDK
2. Откройте файл решения `AppTimeTracker.sln` в Visual Studio
3. Выберите конфигурацию сборки (Debug или Release)
4. Выполните сборку решения (Build → Build Solution или `Ctrl+Shift+B`)
Альтернативно, вы можете собрать проект из командной строки:
```bash
dotnet build AppTimeTracker.sln
```
## ▶️ Запуск проекта
### Из Visual Studio
1. Нажмите `F5` или выберите Debug → Start Debugging
2. Или нажмите `Ctrl+F5` для запуска без отладки
### Из командной строки
```bash
dotnet run --project AppTimeTracker.csproj
```
### Запуск скомпилированного приложения
После сборки исполняемый файл будет находиться в:
- `bin/Debug/net8.0-windows/` (для Debug-сборки)
- `bin/Release/net8.0-windows/` (для Release-сборки)
Запустите файл `AppTimeTracker.exe` из соответствующей директории.
## 📝 Использование
1. Запустите приложение
2. Приложение автоматически начнёт отслеживать активные приложения
3. Просматривайте статистику в реальном времени в главном окне
4. Используйте кнопку "Refresh" для обновления списка
5. Приложения отображаются с общим временем использования в формате `чч:мм:сс`
